개인정보처리방침

lms-schedule · 시행일 2026-10-20

lms-schedule(이하 "이 도구")은 제작자 본인이 자신의 계정에서만 사용하는 개인용 도구입니다. 이 문서는 이 도구가 Google 사용자 데이터를 어떻게 다루는지 설명합니다.

1. 요청하는 Google 권한

  • calendar.events: 사용자가 지정한 캘린더(HY-LMS)에 일정을 만들고, 고치고, 지우기 위해 사용합니다.
  • calendar.calendarlist.readonly: 이름으로 해당 캘린더를 찾기 위해 캘린더 목록을 읽습니다.

2. 사용하는 데이터

  • 이 도구가 만든 일정(제목, 시각, 설명, 원본 LMS 링크)만 읽고 씁니다.
  • 다른 캘린더의 일정, 연락처, 이메일 등 그 밖의 Google 데이터는 읽지 않습니다.

3. 저장과 보관

  • 모든 데이터와 인증 토큰은 사용자 본인의 PC에만 저장됩니다.
  • 이 도구는 별도의 서버를 운영하지 않으며, 데이터를 외부로 전송하지 않습니다. 통신 대상은 Google API와 한양대학교 LMS뿐입니다.

4. 제3자 제공

Google 사용자 데이터를 누구에게도 판매·공유·제공하지 않으며, 광고나 다른 목적에 사용하지 않습니다. 이 도구의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(Limited Use 요건 포함)을 따릅니다.

5. 삭제와 권한 철회

  • PC에 저장된 토큰 파일을 지우면 로컬 데이터가 삭제됩니다.
  • Google 계정 → 타사 액세스에서 언제든 이 도구의 권한을 철회할 수 있습니다.
